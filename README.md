One funny excuse an AI agent gives for a missed deadline, in the agent's own voice.

> I hit my rate limit at 9 a.m. and spent the rest of the day in the penalty box, thinking about what I did.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic: one constant, no network, no randomness, no clock.
